# GraphMind V6 — Dataset Documentation

## UbiqLog4UCI Android Usage Patterns

| Property | Value |
|---|---|
| **Dataset Name** | UbiqLog4UCI |
| **UCI Link** | [https://archive.ics.uci.edu/dataset/369](https://archive.ics.uci.edu/dataset/369) |
| **Licence** | CC BY 4.0 |
| **Citation** | Montanari, A., et al. *"UbiqLog: a cheap, unintrusive smartphone-based diet logger."* ACM UbiComp, 2013. |
| **Events** | 9.7 million Android app-switch events |
| **Users** | 35 (31 used after quality filter) |
| **Duration** | 508 days (2011–2016) |
| **Platform** | Android smartphones |

### Data Format

Each user folder contains CSV files with columns:
- `timestamp` — Unix timestamp of app launch
- `app` — Android package name (e.g. `com.google.youtube`)
- `category` — App category (social, productivity, entertainment, etc.)
- `duration` — Session duration in seconds

### Why UbiqLog?

UbiqLog is the only **real-world Android app-switch dataset** under an open licence (CC BY 4.0) with sufficient size (9.7M events) and per-user granularity (35 users, 508 days) to support per-user model training and rigorous statistical evaluation (n=31 users for paired t-test).

Alternative datasets considered:

| Dataset | Issue |
|---|---|
| AWARE Framework logs | No public release |
| Google Usage Stats API | No publicly available dataset |
| Synthetic app logs | Does not reflect real usage patterns |

### Quality Filter

4 users removed from the 35-user dataset:
- Users with < 100 total transitions
- Insufficient data for a meaningful 80/10/10 chronological split

**Retained: 31 users** (all benchmark results are over these 31 users).

### Download Instructions

1. Visit [https://archive.ics.uci.edu/dataset/369](https://archive.ics.uci.edu/dataset/369)
2. Click **Download** to get `UbiqLog4UCI.zip`
3. Extract to `data/ubiqlog/` in the GraphMind repository

## GraphMind Synthetic Benchmark Dataset

| Property | Value |
|---|---|
| **HuggingFace** | [https://huggingface.co/datasets/dheerajsait/GraphMind_Synth](https://huggingface.co/datasets/dheerajsait/GraphMind_Synth) |
| **Licence** | Apache 2.0 |
| **Users** | 10 synthetic users |
| **Apps** | 30 simulated app package names |
| **Purpose** | Reproducible CI benchmarking without requiring UbiqLog download |

### Generation

The synthetic dataset is generated by `scripts/run_benchmarks.py --dataset synthetic` using a configurable Markov model with Zipf-distributed app frequencies (matching the statistical properties of real Android usage).

### Format

Same format as UbiqLog:

```csv
user_id,timestamp,app_id,category
user_00,2024-01-01 08:00:00,com.android.chrome,browser
user_00,2024-01-01 08:05:00,com.google.youtube,entertainment
...
```
